# 소비컷 (Sobicut) — Frontend

> 대학생 충동 소비 감지 및 소비 패턴 분석 서비스

소비컷은 얼마를 썼는지가 아니라, **어떻게 쓰고 있는지** 알려주며 자신의 소비 패턴을 스스로 인식하고 교정할 수 있도록 돕는 소비 관리 서비스입니다.
결제 문자를 복사하면 자동으로 기록하고, 소비 맥락 태그를 바탕으로 충동지수·지갑 온도·소비 성향을 직관적으로 보여줍니다.

![소비컷 포스터](docs/poster.png)

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 자동 기록 | 결제 문자를 복사해 두면 진입 시 금액·가맹점·시각을 추출하고 카테고리를 분류해 입력 |
| 소비 요인 태그 | 기록 직후 소비 맥락 태그 선택(충동점수에 반영), 나만의 태그 생성(기록용) |
| 충동지수 · 지갑 온도 | 거래별 충동점수(0~100)와 월평균, 예산 대비 지갑 온도 및 또래 평균 비교 |
| 소비 패턴 리포트 | 요일·시간대 히트맵, 카테고리별 지출, BPTI 레이더 차트, LLM 주간 처방전 |
| 사전 경고 알림 | 취약 시간대·예산 초과·충동지수 단계 도달 시 웹 푸시 (5종 개별 설정) |
| 레벨 · 보상 | 기록·태깅·만족도 입력 시 경험치를 얻어 소비 정령 '커티'가 7단계로 성장 |
| 소셜 로그인 | 카카오 로그인 지원 |

## 기술 스택

- React 19 + TypeScript + Vite 6
- styled-components, React Router 6
- TanStack Query (서버 상태 관리)
- PWA (vite-plugin-pwa, Workbox), Web Push
- 배포: Vercel

## 시작하기

### 설치 및 실행

```bash
npm install
npm run dev
```

## 프로젝트 구조

```
src/
├── api/          # 백엔드 API 호출 
├── assets/       # 이미지, 캐릭터, 아이콘
├── components/   # 공통 컴포넌트 
├── hooks/        # React Query 훅, 클립보드 캡처 훅
├── pages/        # 화면 
├── styles/       # 공통 styled-components 스타일
├── types/        # 타입 정의
└── utils/        # 결제 문자 파싱, 카테고리 분류, 푸시, 카카오 SDK 등
```
