# 소비컷 데모 대본 (총 약 3분 10~20초)

## 전환 멘트 (10~20초)

> 지금부터 실제 화면으로 시연을 보여드리겠습니다. 저희 서비스의 핵심 기능 네 가지 — 자동 가계부 입력과 소비 태그, 메인 화면의 실시간 소비 지표, 소비 패턴 리포트, 그리고 알림·성장 시스템을 순서대로 보여드리겠습니다.

---

## 1. 카드 결제 문자 자동 입력 + 소비 태그 (약 40초)

**[클립보드에 결제 문자 복사된 상태 → "소비내역 가져오기" 버튼 클릭]**
> 방금 온 카드 결제 문자를 복사해 둔 상태에서, 이 버튼 하나만 누르면—

**[파싱 결과 화면 전환 — 가맹점/금액/날짜 자동 채워짐]**
> —가맹점, 금액, 날짜가 자동으로 채워집니다. 직접 타이핑할 필요가 없어요.

**[태그 질문 화면으로 이동 → 계획성 태그(즉흥성/충분한숙고) 선택]**
> 등록 직후에는 이 소비를 미리 계획했는지 바로 태그로 남기고—

**[소비 특성 태그(스트레스/비교회피/장기적가치) 선택]**
> —스트레스를 받아서 샀는지, 남과 비교해서 샀는지 같은 소비 당시의 맥락까지 함께 기록하는 게 저희 서비스의 차별점입니다.

---

## 2. 메인 화면 - 지갑온도 · 충동지수 (약 20초)

**[홈 화면으로 이동]**
> 홈 화면에서는 이번 달 지갑 온도와 충동지수를 한눈에 확인할 수 있습니다.

**[지갑온도 / 충동지수 수치 가리키기]**
> 온도가 높을수록 예산 대비 지출이 많다는 뜻이고, 충동지수는 계획 없이 감정적으로 쓴 소비가 많을수록 올라갑니다.

---

## 3. 리포트 페이지 (약 60초)

**[분석 탭 → 리포트 페이지 이동]**
> 소비 패턴은 리포트 페이지에서 더 자세히 볼 수 있습니다.

**[예산 현황 카드]**
> 먼저 이번 달 예산 대비 지출 현황이 나오고—

**[카테고리별 지출 화면]**
> —카테고리별로 어디에 가장 많이 썼는지 보여줍니다.

**[히트맵 화면]**
> 이 히트맵은 요일별, 시간대별로 소비가 몰리는 시점을 짚어줘서 "나는 주로 금요일 밤에 과소비한다" 같은 패턴을 스스로 발견할 수 있게 해줍니다.

**[충동지수 상세 화면]**
> 충동지수는 이번 달 평균 추이로 보여주고, 일정 기준을 넘으면 단계별로 알림이 갑니다.

**[BPTI 카드]**
> 그리고 소비 태그 데이터를 기반으로 5가지 소비 성향 중 하나로 분류하는 BPTI 결과도 함께 제공합니다.

**[지갑온도 카드]**
> 지갑온도는 지금 예산 대비 얼마나 여유가 있는지를 온도로 직관적으로 보여줘요.

**[만족도 페이지로 빠르게 전환 — 5초컷]**
> 마지막으로 만족도 페이지는 이렇게 구매 후 만족도를 짧게 체크하는 용도입니다.

---

## 4. 마이페이지 → 캘린더 지출 추가 → 알림 · 레벨업 (약 40초)

**[마이페이지 이동]**
> 마지막으로 마이페이지를 먼저 보여드릴게요. 지금 레벨과 캐릭터, 이번 달 예산 상태가 나와 있습니다.

**[캘린더 이동 → "+" 버튼 눌러 지출 추가]**
> 이제 캘린더에서 지출을 하나 추가해보겠습니다.

**[금액 입력 후 등록]**
> 이 지출 하나로 이번 달 예산을 초과하게 되는데—

**[알림 확인]**
> —바로 예산 초과 알림이 뜨는 걸 확인하실 수 있고,

**[다시 마이페이지로 이동 → 레벨/exp 확인]**
> 마이페이지로 돌아가 보면 방금 기록으로 경험치가 쌓여서 레벨도 올라간 걸 보실 수 있습니다.
