# 소비컷 프론트엔드

Vite + React + TypeScript 기반 PWA. 대학생을 위한 소비 습관 관리 서비스.

## 개발 시작

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
npm run preview
```

## 스택

- Vite + React 19 + TypeScript
- react-router-dom (라우팅)
- vite-plugin-pwa (PWA 매니페스트 / 서비스워커)
